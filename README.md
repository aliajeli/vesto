# Vesto — فروشگاه اینترنتی پوشاک

فروشگاه آنلاین حرفه‌ای و تجاری پوشاک با **Next.js 15 (App Router)**، **JavaScript خالص** (بدون TypeScript)، **Prisma + SQLite**، رابط کاربری **فارسی RTL** و پنل مدیریت کامل.

## ویژگی‌ها

### فروشگاه
- صفحه اصلی با نمایش **محصولات تخفیف‌دار در بخش نخست**
- جستجو و فیلتر پیشرفته: دسته‌بندی، برند، سایز، رنگ، بازه قیمت، موجودی، مرتب‌سازی
- صفحه محصول با گالری، انتخاب سایز/رنگ، موجودی لحظه‌ای، محصولات مرتبط و نظرات
- **سبد خرید حرفه‌ای** با ذخیره در `localStorage` و قیمت‌گذاری مجدد سمت سرور
- تسویه‌حساب با پشتیبانی از خرید مهمان، آدرس‌دهی و **سیستم کد تخفیف**
- پیگیری سفارش با شماره سفارش و موبایل
- حساب کاربری: سفارش‌ها، آدرس‌ها، علاقه‌مندی‌ها
- **PWA کامل**: نصب روی موبایل، حالت آفلاین، Service Worker و ۴ شورتکات

### پنل مدیریت (`/admin/panel`)
> پنل **هیچ لینک یا دکمه‌ای در سایت ندارد** و فقط با آدرس مستقیم قابل دسترسی است.

| صفحه | امکانات |
|---|---|
| داشبورد | ۶ کارت آماری، نمودار درآمد، وضعیت سفارش‌ها، فروش ساعتی، پرفروش‌ها، هشدار انبار |
| تحلیل فروش | گزارش **ساعتی / روزانه / ماهانه / سالانه**، سود، سهم دسته‌بندی، سایز و رنگ، عملکرد درگاه‌ها و کدهای تخفیف |
| حسابداری | **صورت سود و زیان**، **دفتر کل دوطرفه** (تراز خودکار)، ثبت هزینه، ارزش‌گذاری انبار |
| محصولات | افزودن/ویرایش با تصاویر، تنوع سایز و رنگ، بهای تمام‌شده، حاشیه سود، سئو |
| دسته‌بندی‌ها | ساختار درختی، برندها، ترتیب نمایش، آیکون و تصویر |
| سفارش‌ها | جریان وضعیت کنترل‌شده، کد رهگیری، جزئیات پرداخت، چاپ فاکتور |
| کدهای تخفیف | درصدی/ثابت، سقف، ظرفیت، بازه زمانی، محاسبه بازگشت سرمایه |
| نظرات | تأیید تک‌به‌تک و گروهی، بازمحاسبه خودکار امتیاز محصول |
| مشتریان | سطح‌بندی (پلاتینیوم تا برنزی)، ارزش طول عمر، پراکندگی جغرافیایی |
| ظاهر و تم | **۸ تم رنگی** و **۴ چیدمان** با پیش‌نمایش زنده، فونت، لوگو، بنر |
| تنظیمات | مالیات، ارسال، درگاه پرداخت، اطلاعات تماس، قوانین، حالت تعمیر |
| حسابرسی و امنیت | لاگ کامل رویدادها، بررسی خودکار سلامت، پایش تلاش‌های نفوذ |

### درگاه‌های پرداخت
پیاده‌سازی کامل **زیبال**، **زرین‌پال (v4)** و **پی‌پینگ** به‌همراه **شبیه‌ساز داخلی** برای تست.
کلیدهای Merchant از پنل مدیریت وارد می‌شوند و هرگز در کد قرار نمی‌گیرند.

### امنیت
- تأیید تراکنش **سرور-به-سرور** با **۷ لایه محافظت ضدجعل**
- امضای `HMAC-SHA256` روی `orderId | amount | gateway`
- مبلغ همیشه از دیتابیس خوانده می‌شود، نه از درخواست کاربر
- `idempotencyKey` و به‌روزرسانی شرطی برای جلوگیری از **replay**
- نشست JWT با کوکی `httpOnly` + توکن **CSRF** دوگانه + بررسی هم‌مبدأ
- قفل حساب پس از ۵ ورود ناموفق، محدودسازی نرخ درخواست روی همه مسیرهای حساس
- پاکسازی ورودی‌ها، `Content-Security-Policy`، `HSTS` و `X-Robots-Tag: noindex` روی پنل

## راه‌اندازی

```bash
# ۱) نصب وابستگی‌ها
npm install

# ۲) ساخت فایل محیطی
cp .env.example .env

# ۳) تولید کلیدهای امن و قرار دادن در .env
openssl rand -hex 32   # برای AUTH_SECRET
openssl rand -hex 32   # برای PAYMENT_HMAC_SECRET

# ۴) ساخت دیتابیس
npx prisma db push

# ۵) داده نمونه (اختیاری ولی توصیه‌شده)
npm run seed

# ۶) اجرا
npm run dev
```

سایت روی `http://localhost:3000` و پنل روی `http://localhost:3000/admin/panel` بالا می‌آید.

### حساب‌های نمونه (پس از seed)

| نقش | نام کاربری | رمز عبور |
|---|---|---|
| مدیر | `admin@vesto.ir` | `Vesto@2024` |
| مشتری | `user1@example.com` … `user12@example.com` | `Test@1234` |

> **هشدار:** پیش از استقرار عملیاتی حتماً رمز مدیر و مقادیر `AUTH_SECRET` و `PAYMENT_HMAC_SECRET` را تغییر دهید.

## استقرار

پروژه روی **Vercel**، **Liara**، **Docker** یا هر میزبان سازگار با Node اجرا می‌شود.

برای محیط عملیاتی توصیه می‌شود دیتابیس از SQLite به **PostgreSQL** مهاجرت کند:

```prisma
// prisma/schema.prisma
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}
```

متغیرهای محیطی لازم: `DATABASE_URL`، `AUTH_SECRET`، `PAYMENT_HMAC_SECRET`، `NEXT_PUBLIC_SITE_URL`.
